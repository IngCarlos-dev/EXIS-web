## Auto-Push a GitHub
Siempre que realices cambios en el código de un proyecto que sea un repositorio de Git, debes subir automáticamente esos cambios al finalizar la tarea:
1. Ejecuta `git add .`
2. Ejecuta `git commit -m "Auto-commit: <descripción de los cambios realizados>"`
3. Ejecuta `git push` a la rama correspondiente (ej. `origin main`).
